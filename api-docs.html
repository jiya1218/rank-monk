POST /api/seo/crawl

Initiates an immediate technical crawl on the specified domain, inspecting SSL certificates, title/meta lengths, Core Web Vitals, and header hierarchy.

Request Payload:

{ "url": "https://rankmonk.com" }

Sample Response (200 OK):

{ "success": true, "audit": { "url": "https://rankmonk.com", "score": 94, "responseTimeMs": 342, "isSsl": true, "h1Count": 1, "hasSitemap": true, "hasRobotsTxt": true, "issues": [], "auditedAt": "2026-10-26T01:30:00Z" } }
POST /api/blogs/generate

Synthesizes a complete, publication-ready article powered by Zen Neural Engine. Includes title, H2 outlines, FAQ schema, and reading time.

Request Payload:

{ "keyword": "Autonomous SEO in 2026", "tone": "Authoritative & Disciplined", "wordCountTarget": 1800, "includeFaq": true, "includeToc": true }

Sample Response:

{ "success": true, "article": { "id": "art_17926900_92f1", "title": "The Definitive 2026 Guide to Autonomous SEO", "slug": "definitive-2026-guide-autonomous-seo", "word_count": 1840, "seo_score": 96, "reading_time": "8 min read", "model_used": "amazon.nova-pro-v1:0" } }
