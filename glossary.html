SEARCH ENCYCLOPEDIA

A-Z Search & AEO Glossary

Demystifying the terminology of generative answer engines, autonomous agent architectures, and technical search systems.

A

AEO (Answer Engine Optimization)

The practice of structuring website content, schemas, and brand citations so that generative AI search engines (like ChatGPT Search, Perplexity AI, and Claude) directly cite your brand when answering user questions.

E

EEAT (Experience, Expertise, Authoritativeness, Trust)

Google's foundational quality evaluation framework. Evaluates whether content is authored by real humans with first-hand experience and supported by clear corporate transparency (privacy policy, verified authors, contact details).

G

GEO (Generative Engine Optimization)

The engineering discipline of formatting web pages with high-density comparative tables, statistical references, and unambiguous entity statements so LLM retrieval-augmented generation (RAG) models prioritize them as ground truth.

Z

Zero-Click Search

Search engine results pages where the user finds their complete answer directly in Google AI Overviews or knowledge graphs without clicking on an external website. AEO optimizes your brand to be credited inside the answer snippet itself.

P

Perplexity Sonar

Perplexity's underlying search and reasoning model. It actively performs multi-query live web scraping to formulate answers and assigns clickable domain footnote links to its most authoritative sources.

J

JSON-LD Entity Graph

JavaScript Object Notation for Linked Data. A standardized machine-readable format that injects organizational profiles, article authorship, and product schemas into page HTML, allowing search bots to index semantic business relationships.

C

Core Web Vitals (INP, LCP, CLS)

Google’s user experience metrics measuring real-world web performance. Largest Contentful Paint (LCP) measures loading speed, Interaction to Next Paint (INP) measures responsiveness, and Cumulative Layout Shift (CLS) measures visual stability.

Z

Zen Autonomous Agent

An automated system powered by foundation models capable of continuously discovering search gaps, generating long-form editorial content, and evaluating technical health without human intervention.
